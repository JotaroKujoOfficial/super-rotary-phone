# Cat AI Companion

A mobile Android prototype with a wild black cat face, giant white cartoon eyes, and many reactive moods.

This app is designed as a smart companion UI for a user-focused assistant. It does not perform real screen reading or send user data anywhere.

## How to get APK from GitHub Actions

1. Open the repository in GitHub.
2. Go to Actions.
3. Click the workflow named Build Android APK.
4. Wait until the job finishes.
5. Open the artifact in the workflow result.
6. Download the APK and install it on the phone.
